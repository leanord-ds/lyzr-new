Five moments worth pressing play for

Short on time? Pick up where you want.

  1. A vector database is not a memory system

    Retrieval finds a relevant chunk. It doesn't carry what an agent learned, or why it decided what it decided.

    • A static knowledge base
    Knowledge that evolves

  2. Meko: shared memory at the database layer

    Agent-native infrastructure on YugabyteDB. Four things that used to live in four separate stores — memory, knowledge, conversation history, observability — in one place.

    • Memory
    • Knowledge
    • Conversation history
    • Observability

  3. Datapacks, and reasoning that travels

    The demo is where it gets concrete. Each agent keeps private memory, knowledge stays shareable, and the thinking behind a result is kept with it.

    • DatapackPortable, multi-tenant store: private memory, shared knowledge.
    • Decision tracingThe next agent inherits the reasoning, not just the output.
    • Agent actionsCalls like add knowledge, instead of raw plumbing.

  4. Knowledge that compounds instead of resetting

    A knowledge base that never changes starts going stale the day it ships.

    Context should compound across agents, not end with each session.

  5. The agents Yugabyte runs on itself

    Where its own teams use agents, and what open-source growth, ABM and enterprise go-to-market look like when the product is infrastructure.
