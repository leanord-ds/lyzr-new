Reliability2026

Achieving enterprise-grade reliability in LLM systems through consensus-driven decomposed execution

Khush Patel, Siva Surendira, Jithin George, Shreyas Kapale

The Six Sigma Agent architecture treats LLM outputs as probabilistic and designs for failure tolerance rather than assumed correctness. Complex goals are decomposed into verifiable tasks, executed redundantly by multiple agents, and resolved through consensus. This approach delivers stable, enterprise-grade reliability across long, multi-step workflows.

  • 01Decompose complex goals into verifiable tasks
  • 02Execute each task redundantly across multiple agents
  • 03Resolve outputs through consensus

Reliability2025

CAMP: Compositional Agent Modeling Protocol for Multi-Objective Improvement via World Models and Reinforcement Hardening

Khush Patel, Siva Surendira

CAMP provides a structured simulation framework for systematically improving AI agents across real-world scenarios. Agents are evaluated over compositional world models — defined as factorized spaces of user personas and task contexts — with Pareto constraints across accuracy, relevance, and task completion. The framework enables targeted reinforcement hardening through interpretable failure patterns, reframing agent optimization as a disciplined engineering process.

  • 12Trajectories per run
  • 3Objectives: accuracy, relevance, completion
  • ParetoFailure isolation

AgentDefender by Lyzr: A Benchmark Evaluation and Neural Embedding Approach for Agent Prompt Injection

Khush Patel, Siva Surendira

AgentDefender is a neural embedding-based detection system for prompt injection attacks in AI agents. Benchmarked against traditional ML and agent-based methods across multiple datasets, it achieves up to 99% detection accuracy — 3× better than conventional approaches. The paper details practical deployment considerations for robust prompt-level security in production agent systems.

Memory2026

Cognis: Context-Aware Memory for Conversational AI Agents

Khush Patel et al.

Cognis is a unified memory architecture that addresses a core limitation of conversational AI — the inability to build continuity and trust across sessions. It introduces a 15-category semantic Memory Taxonomy organized into two persistence scopes: USER (cross-session, durable) and CONTEXT (session-specific). This structured approach enables agents to maintain deep context, recognize returning users, and build rapport — without leaking state or conflating long-term knowledge with ephemeral conversation detail.

  • 15Categories
  • 2Scopes: user and context
  • BothPersistent cross-session and in-session memory

Architecture2025

Beyond the Ontology: The Rise of Fluid Intelligence

Siva Surendira

For a decade, enterprises have centralised data into rigid Ontologies through ETL pipelines — a model called Crystallised Intelligence. The Lyzr Fluid Intelligence Architecture inverts this entirely: adaptive agents travel directly to the source, reading SQL, PDFs, and APIs in their native state. Schema changes that once broke pipelines are handled on-the-fly. Questions that required weeks of modelling are answered in days. The result is a decentralised, just-in-time semantic layer with zero pipeline debt and real-time data freshness.

  • 0ETL pipelines required
  • DaysSpeed to value, down from months
  • Real-timeData freshness

Additional research

Additional research shaping Lyzr’s enterprise platform.

Four papers covering governance, architecture, and reliability. Tap any title to read the abstract.

Architecture

BATON introduces a relay-based architecture that enables long-running agent systems without cognitive drift. By breaking execution into discrete legs and passing only distilled state via a structured “Baton,” agents retain first-hour clarity while running indefinitely. The result is higher reliability, lower cost, and consistent performance at enterprise scale.

Architecture

This paper introduces Lyzr’s Fluid Intelligence Architecture, which replaces rigid ontologies and ETL pipelines with agent-driven, on-demand reasoning. Agents interpret data directly at the source, structured or unstructured, adapting instantly to new questions and schemas. The result is faster insight with dramatically lower long-term maintenance overhead.

Governance

ACE-V is a governance protocol designed to prevent hallucinations and blind agreement in AI agents. It uses a tri-agent system, proposer, challenger, and judge, where conclusions change only when supported by evidence. This introduces controlled friction that improves correctness without relying on self-policing by a single model.

Governance

Governor is an open-source framework for governing AI agents in production. Using a simple Python decorator, it enables policy enforcement, human-in-the-loop approvals, and state management. Governor provides a lightweight yet powerful foundation for responsible enterprise agent deployment.
