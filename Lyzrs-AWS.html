Security and deployment

How a request moves through your account, and what protects it.

Follow the deployment layer by layer. The diagram highlights each part as you go.

01 · Edge

Every request enters through your edge

Users and apps reach the Studio web app and Lyzr APIs over HTTPS and WebSocket, through AWS WAF.

  • Amazon Route 53 points your domain at the load balancer
  • AWS WAF applies layer-7 protection
  • A shared Application Load Balancer terminates TLS with AWS Certificate Manager

02 · Network

Apps and data live in private subnets

Only the load balancer and NAT gateways sit in public subnets.

  • Lyzr services run on Amazon EKS in private app subnets
  • Data stores sit in private data subnets
  • Stores are reachable only from EKS pod security groups
  • One NAT gateway per Availability Zone for egress

03 · Identity

No static keys in the cluster

Each service gets only the AWS access it needs.

  • A least-privilege IAM role per service through EKS Pod Identity
  • App secrets held in AWS Secrets Manager and mounted through the CSI driver
  • Single sign-on through Keycloak, brokering SAML or OIDC to your identity provider

04 · Encryption

Your keys encrypt every store

Data is encrypted at rest with your keys and in transit with TLS.

  • AWS KMS customer-managed keys on every data store
  • Amazon DocumentDB as a three-node cluster with TLS
  • Amazon ElastiCache replication group with TLS
  • Amazon RDS for PostgreSQL in Multi-AZ

05 · Private access

AWS services are reached privately

Traffic to regional AWS services goes through VPC endpoints with AWS PrivateLink.

  • Amazon Bedrock for models and embeddings, enabled in your Region
  • Amazon S3, Amazon SQS and Amazon SES
  • AWS KMS, AWS Secrets Manager and Amazon CloudWatch

06 · Guardrails

Guardrails and policy on every call

Lyzr SRS applies guardrails to every agent input and output.

  • Lyzr guardrail models run on EKS inside your VPC
  • Amazon Bedrock Guardrails for native AWS policies
  • An OPA policy engine on the cluster
  • Every agent, tool and LLM call traced through OpenTelemetry

07 · Ownership

Lyzr ships the charts; you own the resources

The deployment sits in one account and one Region, and a dedicated account is recommended for isolation.

  • Helm charts delivered through GitOps with ArgoCD
  • Private Amazon ECR images, by cross-account pull or mirrored into your ECR
  • Container logs and metrics in your Amazon CloudWatch
