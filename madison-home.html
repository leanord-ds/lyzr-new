How Madison works

Compliance lives in many places.

Six buildings with no roads between them. When a rule changes or a control breaks, someone carries the pieces from one to the next by hand.

Plexus connects them.

Plexus is the record underneath. It links each rule to its obligations, policies, controls, tests and evidence, so a change can be traced to everything it touches.

Agents do the work.

Agents travel Plexus: they read the rule, draft each edit, test the control and file the evidence. A person approves every change.

  1. Regulations Rule feedsEach rule read and mappedRegulatory change reads the new rule For review
  2. Obligations Rarely written downOne record for each obligationRegulatory change pulls out each obligation For review
  3. Policies Shared drivesLinked to the obligations it answersRegulatory change drafts the policy edit For review
  4. Controls A GRC trackerLinked to the policy it enforcesControl design drafts the control For review
  5. Tests SpreadsheetsLinked to the control it checksControls testing tests each attribute For review
  6. Evidence InboxesFiled against the test it provesControls testing files the evidence For review
