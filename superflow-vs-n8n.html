Approval governance

checkFull

Structured fields, different requirements for approve vs reject, and uploaded files flow natively into the rest of the workflow

removePartial

Custom forms take free-text responses; no branching by approve vs reject; uploaded files need extra handler nodes to route onward.

Operational resilience

checkFull

Every step is journaled; a restart resumes from the point of failure, and a suspended run holds no resources while it waits

removePartial

Surviving a mid-run crash means building your own outbox and replay pattern; a run waiting on something stays in memory the whole time.

Secure enterprise connectivity

checkFull

OAuth2 with automatic refresh, AWS Signature v4, JWT bearer tokens and mTLS all ship built in

removePartial

OAuth2 needs manual configuration; AWS Signature v4 and JWT need custom signing code; mTLS needs a community workaround.
